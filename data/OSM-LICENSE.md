# OpenStreetMap data attribution

The geographic data in `osm-context.json` is © OpenStreetMap contributors and is made available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). See [OpenStreetMap copyright and attribution](https://www.openstreetmap.org/copyright).

The file retains source object identifiers, fixed Overpass queries, retrieval dates and database timestamps. Geometry is simplified for a regional diagram. It is not a navigation dataset, a current road-condition feed, or evidence of company use. Maps and data exports must retain attribution and this license reference.

Five municipality lookups were performed once, sequentially, with an identifying User-Agent and caching. These are town/city reference points, not plant coordinates. The public Nominatim API is not embedded as a generic geocoding service. Any later re-geocoding must follow its [usage policy](https://operations.osmfoundation.org/policies/nominatim/), including rate limits, cache reuse, and restrictions on systematic requests.
